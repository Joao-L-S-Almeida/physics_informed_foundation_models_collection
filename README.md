# A Collection of Physics-Informed Foundation Models

This is a collection of state-of-art foundation models for Physics and others hard sciences, inpsired by [awesome-time-series-papers](https://github.com/TSCenter/awesome-time-series-papers?tab=readme-ov-file#code-resource)

## List of currently deployed Foundation Models for Physics
1. Walrus - [Walrus: A Cross-Domain Foundation Model for Continuum Dynamic](https://arxiv.org/pdf/2511.15684)
2. Poseidon - [Poseidon: Efficient Foundation Models for PDEs](https://github.com/camlab-ethz/poseidon)
3. GPhyT - [Poseidon: Efficient Foundation Models for PDEs](https://arxiv.org/pdf/2509.13805)
